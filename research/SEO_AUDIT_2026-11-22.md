## Main keyword and cannibalization fix

- `/` is the **sole eligible URL** for the broad `grams to cups` search intent.
- `/cooking/grams-to-cups/` remains operational for direct visits but is **noindex** to avoid competing with the homepage.
- Generated internal text and directory-card links for that intent now point to `/`.
- No speculative 301 was added; there is no confirmed historical indexed URL requiring that redirect.
- 66 routes are presently eligible for a *production* sitemap after `SITE_URL`, branch and publication approval gates; the production domain is **not yet verified** in this audit.

## The 27 candidates with no mapping in this sample

Absence from a partial top-rows export is **not evidence of zero demand**. These candidates include food-specific entries, printable charts and supporting information pages. Some are useful to visitors even if they do not warrant standalone organic targeting.

The website currently does **not** generate a separate page for every keyword, and should never auto-index programmatic pages only because a URL or a numeric search query can be generated. For every candidate check:

1. Does the page answer an independent search intent rather than duplicate the homepage or another converter?
2. Is its ingredient/measurement reference correct, with a visible source and food state?
3. Does it provide differentiated function or information, not just a new number in a title?
4. Is there observed competitor keyword or page evidence? Missing sample evidence should stay explicitly marked *unknown*.
5. Should its permanent URL be included in the production sitemap, or should it remain a navigable noindex support page?

## Reproducible technical checks

Running `npm run build` performs unit tests, JavaScript syntax checks, generates all site pages and robots/canonical/sitemap policy, audits internal URLs, and runs the keyword evidence classifier.

The GitHub workflow **Site build and tests** also simulates an approved production environment and preserves three downloadable artifacts for 30 days:

- `seo-keyword-decisions.csv`: all 2,300 row-level decisions with source keyword, US volume, KD, competitor URL and target status.
- `seo-page-evidence.csv`: all 81 pages with index policy, mapped keyword counts and observed sample estimates.
- `seo-summary.json`: counts, source coverage and classification totals.

Find them at GitHub → Actions → latest successful **Site build and tests** → **Artifacts** → `grams-to-cups-seo-review`.

These files are generated in an ignored `reports/` directory and are intentionally excluded from the Cloudflare `dist/` deployment.

## Still required for actual final release

A verified stable hostname; live Cloudflare build; Lighthouse/Core Web Vitals and real-browser smoke tests against production; final source and page copy review; Google Search Console ownership and sitemap submission; AdSense or other monetization setup only if desired/eligible. The site is designed to minimize ongoing operations, but no SEO or ad monetization outcome is guaranteed.
